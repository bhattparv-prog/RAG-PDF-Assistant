### RAG-PDF-Assistant | AI-Powered Document Chatbot
**Tech Stack:** Python, LangChain, Hugging Face, ChromaDB, Ollama, Streamlit

- Built an AI-powered PDF question-answering application using Retrieval-Augmented Generation (RAG).
- Integrated document processing, text chunking, vector embeddings, and semantic retrieval.
- Implemented ChromaDB for vector storage and Ollama for local LLM-based response generation.
- Developed an interactive interface for querying PDF documents and retrieving context-based answers.
- Utilized AI-assisted development tools for application development, code generation, debugging, and implementation.
